# 飞牛NAS 集成

> 通过 fnOS WebSocket (WSS) 协议在 Home Assistant 中监控飞牛NAS设备。

## 功能

### 系统监控
| 传感器 | 说明 |
|---|---|
| 机器类型 | NAS 机型标识 |
| CPU使用率 | 总使用率 % |
| CPU核心数 | 物理核心数 |
| CPU温度 | 封装温度 °C |
| 内存总量 | 总内存，MB/GB/TB 智能显示 |
| 内存已用 | 已用内存 |
| 内存使用率 | 百分比 |
| 存储总容量 | 所有存储池总容量 |
| 存储可用空间 | 所有存储池可用空间 |
| 系统盘类型 | 系统盘介质类型 |

### 磁盘监控（每块物理盘）
| 传感器 | 说明 |
|---|---|
| 型号 | 磁盘型号 |
| 序列号 | 磁盘序列号 |
| 温度 | 当前温度 °C |
| 健康状态 | SMART 健康状态（良好/故障） |
| 通电时长 | 累计通电小时数 |
| 寿命消耗 | SSD 磨损百分比 |
| 健康状态异常 | 二元传感器（SMART 异常时亮起） |

### 存储池监控（每个存储池）
| 传感器 | 说明 |
|---|---|
| 总容量 | 存储池总容量 |
| 可用空间 | 可用空间 |
| 使用率 | 百分比 |
| RAID级别 | RAID 类型 |

### 系统控制
| 按钮 | 说明 |
|---|---|
| 重启 | 重启 fnOS 系统 |
| 关机 | 关闭 fnOS 系统 |
| 开机 | 通过 Wake-on-LAN 魔术包唤醒 NAS（需配置 MAC 地址） |

> **关机/重启（错误码 266240）**：fnOS 会在设备侧拦截 WebSocket 关机 API（常见诱因：未结束的虚拟机/Docker/活动任务，或关闭了 API 关机权限）。因此本集成的**关机/重启按钮固定走 SSH**，通过 `sudo shutdown -h now` / `sudo reboot` 可靠执行（`sudo` 在登录用户非 root 时自动复用登录密码）。

> **开机（Wake-on-LAN）**：SSH 只能关机，开机需发 WoL 魔术包。添加集成时会**自动通过 SSH 获取网卡 MAC**（多网卡弹出选择，单网卡自动填入），保存后即出现「开机」按钮；也可在集成的「配置」选项流中重设或手动填写。生效条件：NAS 已开启 WoL（BIOS/UEFI + fnOS 电源管理），且 Home Assistant 与 NAS 在**同一局域网/广播域**（跨子网/VLAN 的广播通常无法到达）。

## 安装

### HACS（推荐）

1. 进入 **HACS** → 自定义存储库
2. 添加存储库：`https://github.com/xiaochao99/fn_nas`
3. 搜索"飞牛NAS"，点击下载
4. **重启 Home Assistant**

### 手动安装

将 `custom_components/fn_nas/` 目录复制到 Home Assistant 的 `custom_components/` 目录下，重启。

## 配置

1. **设置** → **设备与服务** → 添加集成 → 搜索"飞牛NAS"
2. 填写以下参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| 主机 | 是 | NAS IP 地址或域名 |
| 协议 | 否 | `auto`（自动）、`ws`（明文，默认端口 5666）、`wss`（加密，默认端口 5667） |
| 端口 | 否 | WebSocket 端口，留空使用协议默认端口 |
| 跳过 TLS 验证 | 否 | 自签证书环境勾选 |
| 用户名 | 是 | fnOS 登录用户名 |
| 密码 | 是 | fnOS 登录密码 |
| 扫描间隔 | 否 | 数据刷新间隔（秒），默认 30 |
| 忽略磁盘 | 否 | 逗号分隔的设备名列表（如 `sda,sdb`），对这些磁盘不创建实体 |
| SSH 端口 | 否 | SSH 端口，默认 22。用于关机/重启按钮（固定走 SSH）以及在添加时自动获取 WoL 的网卡 MAC |

> **SSH sudo 密码**：添加向导不再单独收集。若登录用户不是 root，集成自动复用**登录密码**作为 sudo 密码执行 `sudo shutdown`/`reboot`。

> **MAC 地址 / 网络唤醒开机**：添加集成时自动通过 SSH（`ip link`）探测网卡 MAC——多网卡弹出选择、单网卡自动填入；SSH 不可用 / 未解析到 MAC 时，添加向导会改为显示一个**手动填写框**（可留空跳过），无需事后再进「配置」选项流。无论哪种方式，只要保存了 MAC，「开机」按钮即出现。也可随时在「配置」选项流中重选或手动填写。

### 协议选择

| 场景 | 协议 | 端口 |
|---|---|---|
| 本机（HA 与 NAS 同机部署） | `ws` | `5666` |
| 局域网 IPv4/IPv6 | `wss` | `5667` |
| 公网域名（经反向代理） | `wss` | `443` |
| 不确定 | `auto` | 自动探测 |

## 原理

集成通过 fnOS 的 WebSocket 监控 API 工作，每次刷新流程：

1. WebSocket 连接 NAS
2. 调用 `user.login` 完成认证
3. 依次拉取系统信息、CPU（含温度）、内存、存储空间、磁盘列表
4. 逐盘查询 SMART（型号/序列号/温度/健康），休眠盘通过备用接口获取基本信息
5. 查询存储池列表
6. 会话自动续期，过期后自动重登录

数据获取全程走 WebSocket，**无需 SSH**。但**关机/重启按钮固定走 SSH**（fnOS 的 WebSocket 关机 API 在部分固件被拒，错误码 266240），通过 `sudo shutdown -h now` / `sudo reboot` 执行；添加集成时也会借同一 SSH 连接自动获取网卡 MAC 用于网络唤醒开机。SSH 依赖 `asyncssh`，由 HACS 自动安装。

## 要求

- fnOS 固件版本：支持 WSS 监控 API 的版本
- Home Assistant：2024.1.0+
- NAS 与 HA 网络可达

## 常见问题

**Q: 部分磁盘不显示型号/序列号？**

A: 磁盘处于休眠状态时 SMART 数据不可用，集成会自动通过备用接口获取。若仍缺失，请开启调试日志（`custom_components.fn_nas.wss_client`）查看完整 API 响应。

**Q: 日志中出现 session error / re-authenticating？**

A: 这是正常的会话自动续期机制（DEBUG 级别），不影响使用。

**Q: 存储容量单位如何切换？**

A: 在实体设置中切换"计量单位"（MB/GB/TB），HA 内置换算系统会精确显示。
